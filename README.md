## Overview

Lumen is an open-source Chromium-based browser engineered for privacy, performance, and total control.

With built-in CPU & RAM limiters, tracker blocking, tab hibernation, sandboxed profiles, and a full modding system, Lumen gives users complete control over how their browser behaves.

Fast, lightweight, customizable, and privacy-focused by default.

---

## Features

### Privacy First
- Google telemetry removed
- Built-in tracker blocking
- Fingerprinting protection
- Minimal data collection
- Optional anonymous crash reporting

### Performance Control
- CPU usage limiter
- RAM usage limiter
- Per-tab resource controls
- Tab hibernation
- Optimized Chromium core

### Customization
- Full extension API support
- Manifest V3 compatibility
- Lumen Mod SDK
- UI themes and modifications
- Community-created mods

### Isolation & Security
- Sandboxed browser profiles
- Isolated storage environments
- Secure browsing architecture
- Separate extension containers

## Philosophy

Lumen exists because modern browsers have become increasingly bloated, invasive, and restrictive.

We believe users deserve:
- Privacy by default
- Transparent software
- Real control over system resources
- A browser that can be customized freely

No spyware. No unnecessary telemetry.
